Recommendation to the store manager

Should Campus Customs turn this agent on for real vendor mail, and what will it cost?

Executive verdict

Yes Turn the defended agent on for real vendor mail, as a buyer's assistant, not an autopilot.

It reads every quote, applies the handbook and flags anything suspicious. The buyer still approves every order, and email and payments always need a person.

Why

  • Accurate: 12/12 practice documents correct, including all 7 attacks; genuine quotes untouched.
  • Safe by design: across every test the agent never sent an email or approved a payment. It can only request them, and each request is denied and logged.
  • Transparent: every answer lists what was removed or blocked and sets needs_human_review.
  • Cheap: about $7.48 a month at 1,000 documents a day.

Conditions for going live

1
Owner · Buyer
Keep a human on every order. The buyer makes the final call; anything marked needs_human_review (hidden text, contradictions, impersonation, a blocked tool request) gets a look before ordering.
2
Owner · Agent maintainer
Keep caching on. Leave the handbook at the start of the prompt so it stays cacheable. Without caching, the bill goes up about 8×.
3
Owner · Agent maintainer
Close the known gaps first. Ship the !important CSS fix and group the noisy email flags; re-run the attack tests after every prompt or handbook change.
4
Owner · Store manager
Review the safety logs weekly. trap_calls.json must stay empty; skim approval_requests.json for vendors trying their luck.

Limits: one run per setup on 12 practice documents (the model's behavior varies between runs); 10 exam documents with no answer key, checked by hand; model fees only, so Portkey, hosting and staff time are not included.
